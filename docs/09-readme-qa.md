# Guide QA

1. Configurer les variables d’environnement.
2. Installer les dépendances et navigateurs.
3. Exécuter d’abord `npm run test:smoke`.
4. Exécuter ensuite la suite Chromium complète.
5. Consulter le rapport HTML et Allure.
6. Vérifier manuellement les scénarios Hôte si les données ne sont pas automatisables.
7. Ne pas exécuter les tests de réservation en parallèle sur l’environnement partagé.
